# VM Underutilisation Dissertation

This project investigates the identification of underutilised virtual machines using a Random Forest classifier, confidence-based recommendations and human feedback.

## Main Components

- Azure Advisor-inspired baseline
- Random Forest classification model
- Confidence-based recommendations
- Human feedback and retraining
- Evaluation of low-confidence review against random review

## Technologies

- Python
- scikit-learn
- Flask
- SQLite
- SciPy
